# BMS测试工具整合版 — 功能描述

## 1. 概述

- **产品名称**：BMS测试工具整合版
- **运行环境**：Windows 10 / Python 3.x + PyQt5
- **启动方式**：`python main.py` 或双击 `run.bat`
- **窗口行为**：默认最大化启动，保留标准标题栏与关闭按钮
- **产品定位**：面向 BMS 开发/测试工程师，统一界面完成进制转换、CAN报文解析、L2/L3 BMS 寄存器监控、报警测试等日常工作

## 2. 整体架构

- **入口**：`main.py`，创建 `MainWindow`，全局应用字体与统一样式
- **Tab 隔离**：每个标签页都是独立 `QWidget`，不跨 Tab 直接引用实例
- **共享模块**：`shared/` 提供通信、协议解析、样式等公共能力
- **协议定义**：`l2_protocol/`、`l3_protocol/` 存放寄存器与分组配置
- **日志**：`logs/bms_test.log`，DEBUG 级别，UTF-8 编码

## 3. 主界面结构

- **标题**：BMS测试工具整合版
- **启动尺寸**：最小 1200×900，默认 1400×1200，最大化显示
- **标签页**：共 4 个 Tab，顶部导航

| Tab 名称 | 核心定位 |
|---------|---------|
| 进制转换 | 二进制/八进制/十进制/十六进制/ASCII 互转 |
| CAN报文解析 | CAN ID 与数据帧解析，支持 DBC 解码 |
| BMS监控(L2/L3) | 单个监控 Tab，左侧下拉切换 L2/L3 架构，Modbus RTU 寄存器监控与控制 |
| 报警测试 | 故障码测试、阈值测试、测试报告（汇总两类测试的通过/失败明细） |

## 4. 详细功能说明

### 4.1 进制转换

**功能目标**：快速完成 BMS 调试中常见的进制/编码互转。

- **输入类型**
  - 智能检测：自动识别二进制、八进制、十进制、十六进制或字符串
  - 手动选择：二进制、八进制、十进制、十六进制、字符串
- **转换选项**
  - 实时转换：输入变化时自动刷新结果
  - 二进制4位分组：方便阅读长二进制串
  - 十六进制大写：控制输出大小写
- **输出内容**
  - ASCII字符串
  - 十六进制
  - 十进制
  - 八进制
  - 二进制
- **辅助操作**
  - 一键复制每个输出框结果
  - 一键清空输入与输出
- **业务价值**：排查日志、分析抓包、转换参数时无需再打开多个工具

### 4.2 CAN报文解析

**功能目标**：解析 CAN 报文的 ID 结构与数据内容，支持基于 DBC 的信号级解码。

- **DBC 管理**
  - 导入 DBC：批量选择 `.dbc` 文件
  - 已加载列表：显示当前加载的 DBC 文件
  - 删除选中：移除指定 DBC 文件，重新构建索引
  - CAN ID 自动补全：基于已加载 DBC 的消息 ID 列表提供输入联想
- **CAN 解析**
  - ID 解析：提取优先级、DP、PF、PS、PGN、SA 地址，并映射预设功能说明
  - 数据帧解析：按字节展示十六进制/十进制/二进制/ASCII，并计算常见组合值
    - uint16 LE/BE
    - uint32 LE/BE
    - float32 LE/BE
  - DBC 优先解码：若已加载 DBC 且匹配，直接展示消息名与信号列表
  - 一键复制解析结果
- **业务价值**：分析总线和排查 BMS 通信协议时，可直接完成 ID 结构与信号值解读

### 4.3 BMS监控(L2/L3)

单个监控 Tab 支持 L2/L3 两种架构（同一类 BMS 的不同硬件架构：L2=采集板+主控板，L3=采集板+多主控板+一级主控板）。左侧"架构类型"下拉框即时切换：自动断开连接、重载对应协议、重建信号表格与寄存器视图。协议解码表各自独立，一次只监控一种架构，不存在解析冲突。

#### 4.3.1 连接设置

- 架构类型：L2 / L3 下拉切换（切换时自动断开并重建显示）
- COM口选择：自动枚举系统可用串口
- 波特率：9600、19200、38400、57600、115200
- 从机地址：1~247
- 轮询间隔：0.1~10.0 秒
- 连接/断开：Modbus RTU 串口通信
- 开始监控/停止监控：启动或停止连续轮询

#### 4.3.2 寄存器监控

- **分组展示**：按 `status_tabs` 配置，每个分组一个子 Tab
- **表格列**
  - 信号名
  - 地址（DEC）
  - 原始值（HEX）
  - 原始值（DEC）
  - 因子
  - 偏移
  - 物理值
  - 单位
- **寄存器视图**
  - 以 4xxxx 地址形式连续展示当前监控范围
  - 已采集到原始值的寄存器显示 `<XXXXXXXXH>`
  - 未采集到显示 `<---->`
- **刷新机制**
  - 定时刷新界面显示
  - 串口轮询独立后台线程

#### 4.3.3 控制指令（06H 写寄存器）

- 上下电指令：高压下电 / 放电上电 / 充电上电
- 复位/关机/消音：无效 / 复位 / 关机 / 消音
- 急停报警：正常 / 急停
- 发送前检查连接状态，未连接时直接提示并返回

#### 4.3.4 通信统计

- TX/RX/错误次数统计
- 通信状态指示灯（灰=断开，绿=已连接）
- 清空日志
- 打开协议配置

#### 4.3.5 协议配置（弹窗）

- **可编辑字段**：地址、起始位、结束位、长度、精度、偏移、单位
- **只读字段**：信号名、类型（自动推断）
- **自动联动**：起始位/结束位/长度三值联动计算
- **修改高亮**：与默认值不同的单元格高亮
- **导入 Excel**：解析 Excel 协议文件并替换当前协议配置
- **恢复默认**：清除用户自定义，回到初始配置
- **持久化存储**：`protocol_user_config.json`，L2/L3 分离保存

### 4.4 报警测试

报警测试是一个复合功能 Tab，顶部是 CAN 连接控制栏，主体采用“左侧导航 + 右侧内容区”布局。

#### 4.4.1 CAN 连接控制栏（顶部）

- 连接 CAN / 断开 CAN
- CAN 配置：CH1/CH2 波特率设置
  - CH1：对内调试 CAN，用于发送故障注入报文
  - CH2：对外 CAN，用于接收 BMS 响应报文
- 状态显示：CAN: 未连接 / 连接中... / 已连接 (CH1,CH2) / 连接失败
- TX/RX 计数定时刷新

#### 4.4.2 左侧导航

| 菜单项 | 页面 key |
|-------|---------|
| 故障码测试 | fault |
| 阈值测试 | threshold |
| 测试报告 | report |

#### 4.4.3 故障码测试

- **测试配置**
  - BMS 地址：1~255
  - 域类型：NBCMU / SBCMU
  - 测试范围：所有故障 / NBCMU / SBCMU / 共有故障 / 自定义选择
  - 故障等级过滤：所有等级 / 等级1 / 等级2 / 等级3
- **故障列表**
  - 表格列：选择、故障码、故障名称、故障等级、域类型、对内映射、对外映射
  - 全选 / 全不选 / 反选
  - 刷新列表
  - 搜索：按故障码或名称过滤
  - 进入页面自动加载故障列表，避免空白
- **测试控制**
  - 开始故障测试
  - 停止故障测试
  - 单步测试
  - 进度条 + 进度标签
- **测试详情**
  - 实时日志
  - 验证详情表格：检查类型、检查域、期望值、实际值、状态
- **前置校验**
  - 未连接 CAN 时禁止启动测试，直接日志提示

#### 4.4.4 阈值测试

- **阈值测试配置**
  - BMS 地址：1~255
  - 域类型：NBCMU / SBCMU
  - 测试类型：上限测试 / 下限测试 / 上下限测试
  - 阈值偏移量：0.1%~100%
  - 报警等待时间：1~60 秒
- **PID 列表**
  - 表格列：选择、PID（0xF001）、名称、单位、下限、上限、测试类型、状态
  - 全选 / 全不选 / 反选
  - 刷新列表
  - 搜索：按 PID 或名称过滤
  - 测试类型切换时自动过滤 PID 列表（按阈值走向/名称自动推断适用类型）
- **测试控制**
  - 开始阈值测试 / 停止阈值测试 / 单步测试（同步执行单个 PID 完整流程）
  - 进度条 + 进度标签
- **测试详情**
  - 实时日志
  - 参数详情表格：参数、原始值、设置值、实际报警值、报警状态、测试结果
- **测试流程**：读取基线值 → 按类型（上限/下限/上下限双向）设置越限值 → 等待报警成熟时间 → 验证对外报警信号 → 恢复原始值
- **结果落库**：每个 PID 的测试结果（含阈值设置/报警验证/阈值恢复检查项）实时写入 SQLite，供测试报告汇总

#### 4.4.5 测试报告

- **测试总结标签页（默认）**
  - 汇总卡片：总测试数、通过、失败、通过率、故障码测试（通过/总数）、阈值测试（通过/总数）
  - 通过明细表格：时间、测试类型、编号、名称、耗时、状态
  - 失败明细表格：时间、测试类型、编号、名称、失败原因、状态、明细（双击或点"明细"查看检查项：期望值/实际值/状态）
- **报告控制**
  - 刷新报告 / 清空报告（同时删除数据库记录）/ 加载更多
  - 记录数显示
- **报告过滤**
  - 时间范围：开始日期 ~ 结束日期
  - 测试类型：全部 / 故障码测试 / 阈值测试
  - 测试状态：全部 / 通过 / 失败
  - 故障码过滤
  - BMS 地址过滤（下拉框从数据库动态加载）
- **测试结果标签页**
  - 表格列：时间、故障码、故障名称、测试类型、状态、BMS地址、域类型、持续时间、详情
  - 双击行查看检查项明细弹窗
- **统计信息标签页**
  - 总体统计：总测试数、通过数、失败数、通过率、平均耗时
  - 故障统计：故障码、故障名称、测试次数、通过数、通过率
  - 时间统计：日期、测试次数、通过数、通过率
- **系统日志标签页**
  - 日志级别过滤（INFO/WARNING/ERROR/DEBUG）
  - 清空日志 / 保存日志
- **报告导出**
  - 导出格式：Excel / CSV / HTML
  - 导出范围：当前视图 / 全部记录 / 过滤结果
  - 导出报告 / 打印报告（文本摘要 + 检查项明细）

## 5. 业务价值总结

1. **减少切换成本**：一个工具覆盖转换、解析、监控、测试，避免在多个小工具间切换
2. **提升排查效率**：CAN 报文解析支持 DBC 解码，可直接定位信号含义与异常
3. **规范测试流程**：故障码/阈值测试具备选择、执行、记录、导出完整闭环
4. **配置可维护**：协议配置支持 Excel 导入与用户自定义持久化，适配不同项目

## 6. 使用方式

```bash
# 安装依赖
pip install -r requirements.txt

# 启动
python main.py
```

Windows 用户可直接双击 `run.bat`。

## 8. 运行要求

- Windows 10 及以上
- Python 3.8+
- PyQt5
- 串口依赖：pyserial
- 串口硬件：对应 CAN/串口设备
- CAN/DBC 依赖：cantools（报警测试与 DBC 解码使用）
- 报表导出：openpyxl（导出 Excel 报告）

## 9. 扩展说明

- 新增 Tab：在 `tabs/` 下创建新模块，在 `main.py` 中导入并注册即可，不影响现有页面
- 协议适配：通过 `l2_protocol` / `l3_protocol` 与 `protocol_user_config.json` 实现项目级配置
