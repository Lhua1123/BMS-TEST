# BMS 485 控制指令 / 心跳 报文速查

> 用途：脱离本上位机，用串口助手 / 脚本单独发送 Modbus RTU 帧时对照。
>
> 协议依据：`shared/constants.py`、`shared/modbus_parser.py`、监控页「控制指令(06H)」逻辑。
>
> 默认从站地址 **1**。若设备从站不是 1，只改第 1 字节，并**重算 CRC**（文末有公式）。

---

## 1. 总览

| 功能 | 寄存器地址 | 功能码 | 说明 |
|------|-----------|--------|------|
| **心跳信号（写）** | **1** | 06H 写单寄存器 | 周期写，值 0–255 必须变化 |
| **控制指令** | **2** | 06H 写单寄存器 | 上下电 + 复位/关机/消音 + 急停，打成 1 个 16-bit 值 |
| 心跳（读，可选核对） | 1 | 03H 读保持寄存器 | 读回当前心跳相关值 |
| 控制（读，可选核对） | 2 | 03H 读保持寄存器 | 读回当前控制寄存器 |
| 状态监控（示例） | 20 起 | 03H | 界面「开始监控」从地址 20 批量读 |

**帧格式（06H 写）共 8 字节：**

```
[从站] [06] [地址H] [地址L] [值H] [值L] [CRCL] [CRCH]
```

**成功时设备原样回写整帧**（8 字节，与请求相同）。

## 2. 心跳（写寄存器 1）

### 协议要求

- 地址：**1**（心跳信号-写），**不要**写到地址 2
- 数据：8-bit，**0 → 1 → 2 → … → 255 → 0** 循环
- 建议间隔：**1s**（软件默认）
- **30s 内**只写相同值或未收到心跳 → BMS 报**通信失败（三级报警）**
- 因此：**不能一直写 0**，值必须变

### 操作含义

- 只为保活、不下发控制时：连接 485 后**持续发心跳**即可
- 与控制指令、监控读**可同时进行**（总线分时，一问一答）

### 从站 1 帧样例（值变化时只需改「值」两字节并重算 CRC）

| 含义 | 完整 HEX（可直接发） |
|------|----------------------|
| 心跳值=0 | `01 06 00 01 00 00 D8 0A` |
| 心跳值=1 | `01 06 00 01 00 01 19 CA` |
| 心跳值=2 | `01 06 00 01 00 02 59 CB` |
| 心跳值=3 | `01 06 00 01 00 03 98 0B` |
| 心跳值=4 | `01 06 00 01 00 04 D9 C9` |
| 心跳值=200 | `01 06 00 01 00 C8 D9 9C` |
| 心跳值=255 | `01 06 00 01 00 FF 98 4A` |

**逐字节注释（以心跳值=1 为例）：**

```
01       从站地址 1
06       功能码：写单寄存器
00 01    寄存器地址 1（心跳）
00 01    写入值 = 1（0x0001，高字节在前）
19 CA    CRC16（低字节在前）
```

**从站 2 时心跳值=0 示例：** `02 06 00 01 00 00 D8 39`（仅第 1 字节与 CRC 变化）

## 3. 控制指令（写寄存器 2）

### 寄存器 2 位域

界面与代码按下列位拼一个 16-bit 值后，一次写入地址 2：

```
值 = (上下电 << 0) | (复位类 << 2) | (急停 << 4)
```

| 位域 | 位 | 编码 | 含义 |
|------|----|------|------|
| **上下电** | bit1–0 | 0 | 高压下电 |
| | | 1 | 放电上电 |
| | | 2 | 充电上电 |
| **复位/关机/消音** | bit3–2 | 0 | 无效 |
| | | 1 | 复位 |
| | | 2 | 关机 |
| | | 3 | 消音 |
| **急停报警** | bit4 | 0 | 正常 |
| | | 1 | 急停 |

未勾选的组按 **0**（高压下电 + 无效 + 正常）发送。  
单选可组内组合，例如「放电上电 + 复位」= 1 | (1<<2) = **5**。

### 常用控制帧（从站 1）

| 场景 | 值 | 完整 HEX |
|------|----|----------|
| 默认 / 高压下电 + 无效 + 正常 | 0x0000 | `01 06 00 02 00 00 28 0A` |
| **放电上电** | 0x0001 | `01 06 00 02 00 01 E9 CA` |
| **充电上电** | 0x0002 | `01 06 00 02 00 02 A9 CB` |
| **复位**（上下电位保持 0） | 0x0004 | `01 06 00 02 00 04 29 C9` |
| **关机** | 0x0008 | `01 06 00 02 00 08 29 CC` |
| **消音** | 0x000C | `01 06 00 02 00 0C 28 0F` |
| **急停** | 0x0010 | `01 06 00 02 00 10 29 C6` |
| 放电上电 + 复位 | 0x0005 | `01 06 00 02 00 05 E8 09` |
| 高压下电 + 消音 | 0x000C | `01 06 00 02 00 0C 28 0F` |
| 充电上电 + 关机 + 急停 | 0x001A | `01 06 00 02 00 1A A9 C1` |

**逐字节注释（以急停为例）：**

```
01       从站 1
06       写单寄存器
00 02    寄存器 2（控制指令）
00 10    值 = 16 = 0b0000_0000_0001_0000
              bit4=1 急停；上下电=0 高压下电；复位类=0 无效
29 C6    CRC16
```

**逐字节注释（放电上电 + 复位 = 0x0005）：**

```
01 06 00 02 00 05 E8 09
         ^^^^^ 地址 2
               ^^^^^ 值 5 = 0b0101
                     bit1-0 = 01 → 放电上电
                     bit3-2 = 01 → 复位
                     bit4   = 0  → 急停正常
```

### 组合值速算

```
高压下电=0, 放电上电=1, 充电上电=2
无效=0, 复位=1, 关机=2, 消音=3
急停: 正常=0, 急停=1

寄存器值 = 上下电 + 复位类*4 + 急停*16
```

| 上下电 | 复位类 | 急停 | 值 | 结果寄存器内容 |
|--------|--------|------|-----|----------------|
| 高压下电 0 | 无效 0 | 正常 0 | 0 | 0x0000 |
| 放电上电 1 | 无效 0 | 正常 0 | 1 | 0x0001 |
| 充电上电 2 | 消音 3 | 正常 0 | 2+12=14 | 0x000E |
| 放电上电 1 | 复位 1 | 急停 1 | 1+4+16=21 | 0x0015 |

## 4. 推荐实操顺序（手动 485）

1. 串口参数对齐：波特率（常见 9600）、8N1、从站地址  
2. **持续发心跳**（每 1s 一条，值递增）——保活  
3. 需要控制时，在心跳间隙插入一条控制 06H 帧  
4. 成功：设备应**原帧回写**；失败：无响应或异常码  
5. 不控制时可停发控制帧，**心跳建议一直发到断电/结束**

示例时序（从站 1）：

```
t=0.0s  01 06 00 01 00 00 D8 0A    ← 心跳 0
t=1.0s  01 06 00 01 00 01 19 CA    ← 心跳 1
t=1.5s  01 06 00 02 00 01 E9 CA    ← 放电上电（插在两次心跳之间）
t=2.0s  01 06 00 01 00 02 59 CB    ← 心跳 2
...
```

## 6. 自己拼帧时的 CRC

与本工程 `crc16_modbus` 一致（CRC16/MODBUS，多项式 0xA001，初值 0xFFFF，**低字节在前**）：

```python
def crc16_modbus(data: bytes) -> bytes:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 1:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return bytes([crc & 0xFF, (crc >> 8) & 0xFF])

# 例：心跳值 = n
n = 5
body = bytes([0x01, 0x06, 0x00, 0x01, 0x00, n])
frame = body + crc16_modbus(body)
print(frame.hex(' ').upper())
```

改从站 / 改值 / 改地址后，**必须重算最后 2 字节 CRC**。

## 7. 易错点

| 错误做法 | 后果 |
|----------|------|
| 心跳写到地址 **2** | 会当成控制指令，可能误触发上下电/急停 |
| 心跳一直写 **0** | 30s 后通信失败三级报警 |
| 心跳间隔过长（>30s） | 同上 |
| 改了帧内容不改 CRC | 设备无响应或校验错 |
| 从站地址不对 | 无响应 |
| 与上位机同时开同一 COM | 打不开串口或总线冲突（同一时刻只用一个主站） |

## 8. 和软件界面的对应关系

| 界面 | 实际 485 行为 |
|------|----------------|
| 启动心跳 | 后台每 1s 写寄存器 1，值 0–255 循环 |
| 发送控制指令 | 一次写寄存器 2，值按勾选项拼位 |
| 开始监控 | 周期 03H 从地址 20 起分组读 |
| 停止心跳 / 断开 | 停止写 1；断开会停轮询并关串口 |
